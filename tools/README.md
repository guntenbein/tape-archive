# Служебные скрипты

* `make_synthetic_tape.py` — генерит синтетическую «кассету» с заранее
  известной разметкой: шум ленты, речеподобные фрагменты, настройка
  инструмента, настоящий обрыв исполнения, тот же мотив в другой тональности
  и темпе, **другая аккордовая прогрессия** (отрицательный пример для
  кластеризации), **дословная копия куска** (проверка chromaprint), клиппинг,
  провал уровня. Детерминирован.
* `check_selftest.py` — сверяет результат конвейера с этой разметкой.
  Регрессионный тест: падает, если правка порогов ломает то, что работало.
* `bench_asr.py` — сравнение моделей faster-whisper на CPU по скорости и
  качеству. Запускать на публичных записях, не на личном архиве.
* `restore_a.py` — реставрация музыкальных сегментов с оценкой A. Параметры
  у каждого куска свои, из измерений.
* `restore_talk.py` — реставрация разговорных блоков. Отбор не по оценке, а
  по длине склеенного блока: рейтинг заточен на музыку и короткие реплики
  недооценивает.
* `setup_gdrive.sh` — проверка настроенного remote rclone и выкачивание папки.
  Учётных данных не создаёт, см. [../docs/GDRIVE.md](../docs/GDRIVE.md).
